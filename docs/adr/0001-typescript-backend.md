# Rewrite the backend from Go to TypeScript (Node 22 + Hono)

The backend was rewritten in-place from Go (chi) to TypeScript on Node 22 with Hono. Motivation: keep the number of languages in the project low and deepen TypeScript specialization. The HTTP contract is preserved exactly (routes, status codes, middleware semantics), so the frontend and Caddy needed no changes. Two deliberate deviations from the Go behaviour: `/api/import/detect` streams the upload to album-detector instead of buffering it in memory (a malformed multipart body now reaches album-detector and comes back as its 422, rather than being rejected with a bare 400 by the backend), and MusicBrainz releases with an empty `artist-credit` are skipped instead of crashing the process. The Python album-detector service is deliberately out of scope — OCR/CV stays in Python behind its HTTP boundary.
